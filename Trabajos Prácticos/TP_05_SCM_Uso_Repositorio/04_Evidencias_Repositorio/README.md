# Evidencias del TP 05

Este directorio reúne evidencia del uso real del repositorio durante el cursado de la materia, en cumplimiento del Trabajo Práctico 5.

## Qué guardar aquí

- Capturas del historial de commits.
- Evidencia de `pull`, `fetch`, `update` o sincronización del repositorio.
- Capturas o listados de líneas base creadas.
- Resúmenes breves de participación por integrante.
- Cualquier otra evidencia útil para demostrar evolución del repositorio a lo largo del cursado.

## Criterio de uso

- Cada evidencia debe nombrarse como `TP_05_Evidencia_<Descripcion>_<AAAA-MM-DD>.<ext>`.
- Se recomienda acompañar las capturas con un archivo Markdown que explique el contexto.
- La evidencia debe reflejar participación distribuida entre integrantes y no una sola carga final.

## Archivos actuales

- `TP_05_Seguimiento_Integrantes.md`: seguimiento de commits, actualizaciones y líneas base por integrante.
- `TP_05_Evidencia_EstadoActual_2026-05-26.md`: resumen del estado actual del repositorio, remoto y líneas base existentes.
